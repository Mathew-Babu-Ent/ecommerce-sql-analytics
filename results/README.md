# Query Results

Actual query outputs belong here. Results must come from the local `ecommerce`
database; do not replace them with estimated or illustrative values. Save the
tab-separated output from each analysis script as `04_beginner_analysis.tsv`,
`05_intermediate_analysis.tsv`, and `06_advanced_analysis.tsv`. See
`result_index.md` for the query-to-output mapping and row counts. Findings in
`docs/business_insights.md` cite the relevant script/query IDs.
